## 在每条安装路径上检查

- [ ] App 图标和黑白主界面正常。
- [ ] 允许通知后，30 秒计时结束能收到通知。
- [ ] 回到主屏幕，灵动岛显示剩余时间；长按可看进度（需要相应硬件）。
- [ ] 锁屏能看到实时活动卡片。
- [ ] 计时中重新开始，更新时间，且只收到一次结束通知。
- [ ] 取消计时后，卡片移除、到时不再提醒。
- [ ] 操作按钮绑定“开始休息”后，解锁、锁屏两种状态都能开始或重新计时。
- [ ] 到时停在零，重新打开 App 会清除结束卡片。
- [ ] 使用同一账号与 Bundle ID 覆盖安装后，休息时长设置仍保留。

请记下电脑系统、手机型号、iOS 版本、安装工具版本以及失败步骤。此清单未打勾的项目不代表已在分享路径上实测。
